## 🌸 About the Project

**From My Heart — Birthday Surprise** is a creative, interactive birthday website designed to turn a simple birthday wish into a memorable digital experience.

Instead of sending an ordinary birthday message, you can surprise someone special with glowing wishes, floating hearts, a personalized letter, an animated gift reveal, photos of your favorite moments, and background music.

Whether it is for your girlfriend, best friend, sister, or another special person, the website gives you a way to express your feelings through a personalized online gift.

**The idea is simple:** make someone smile, remind them how special they are, and create a birthday memory they can revisit.

## ✨ Features

| Feature | Description |
|---|---|
| 🎂 Birthday Wish | A birthday greeting with a candle animation. |

## 🎬 The Birthday Surprise Experience

The website brings together several elements to create a special birthday moment:

1. **A warm welcome** — introduce the birthday surprise.

## 🚀 Run the Project Locally

### Prerequisites

- A modern web browser such as Chrome, Edge, or Firefox
- Git, if you want to clone the repository
- A code editor such as Visual Studio Code (optional)

### Step 1 — Clone the repository

Open a terminal and run:

```bash
git clone https://github.com/tharungutta/Birthday_Surprise.git
```

### Step 2 — Open the project folder

```bash
cd Birthday_Surprise
```

### Step 3 — Open the website

Open `index.html` in your browser.

For development, you can also open the folder in Visual Studio Code and use the Live Server extension.

**No build command is required** for the basic HTML, CSS, and JavaScript setup.

## 🎨 How to Personalize the Website

Make the surprise unique to the person receiving it.

### 1. Customize the birthday message

Open `message.html` and replace the existing text with your own birthday letter.

Ideas include:
- A heartfelt birthday wish
- A favorite shared memory
- A message of appreciation
- A funny inside joke

### 2. Change the recipient's name

Open `index.html` and `script.js`. Find the existing birthday text or name and update it to match your recipient.

The exact location depends on how the current code defines the text.

### 3. Add your own photos

1. Open the `images/` folder.
2. Add your favorite pictures.
3. Update the image paths in the HTML or JavaScript if you change any filenames.
4. Check that every image loads correctly.

Use meaningful photos that celebrate your relationship and shared memories.

### 4. Add background music

Place your chosen audio file in the project folder and update the corresponding audio source in the code if necessary.

Use audio that you have permission to use. Remember that browsers may require a user interaction before playing audio.

### 5. Customize the design

Open `style.css` to adjust colors, typography, spacing, animations, and responsive layouts.

You can give the website a romantic pink theme, a soft pastel appearance, or another visual style that suits the occasion.

## 📱 Responsive Design

The website is intended to provide a pleasant experience across different screen sizes.

For the best result, test it on:

- 📱 Mobile phones
